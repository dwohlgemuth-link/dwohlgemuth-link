## 🚀 Featured Work (PWAs & Tools)

Ich baue gerne performante Tools, die direkt im Browser laufen, lokal arbeiten und auf jedem Gerät installierbar sind.

* 🎨 **[SVG Color Analyzer](https://github.com/dwohlgemuth-link/svg-color-analyzer)**
  A high-performance, single-file Web Application (PWA) that parses SVG vector graphics and calculates the exact pixel-by-pixel color distribution using Euclidean distance tolerance.

* 🚂 **[UIC Wagon Number Calculator](https://github.com/dwohlgemuth-link/uic-wagon-number-calculator)**
  A bilingual Progressive Web App computing the check digit (Selbstkontrollziffer) of European train wagons using the Luhn algorithm. Completely responsive and installable.
